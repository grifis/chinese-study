# 教材作成ルール

AGENTS.md の10項目はすべて必須。教科書を中心に管理し、学習補足を上書きに使わない。

| 項目 | JSONキー | 保存するもの |
|---|---|---|
| 本文・基本文 | text | 原文、原番号、全文拼音、日本語訳 |
| 会話 | dialogue | 会話番号・話者、全発話（最終の謝辞も含む） |
| 文法 | grammar | 教科書説明・日本語説明・全例文、別枠の補足 |
| 単語 | vocabulary | 掲載順・原番号・品詞・拼音・原本の意味 |
| 置き換え | replacements | 元文、全候補、候補と同数の完成文・拼音・訳 |
| 広げる | expansion | 全掲載文・拼音・訳。読解用、出題しない |
| 練習 | practice | 原文設問と空欄、原番号、解答例・全文拼音・訳・語句分解・文法・正解理由 |
| 復習クイズ | quiz.json | AI補足であること、全選択肢、正解、解説 |

## 出典と確認状態

- `origin: textbook / status: verified` は原文を原画像で確認した文。添付HTMLだけでこの状態にしない。
- `origin: ai / status: supplement` はAI作成例文・解答。指定候補から作成した完成文も原本に完成文が掲載されていないため補足とする。
- `annotationOrigin: ai / annotationStatus: needs-review` は拼音・訳に校閲待ちがあること。原文の確認状態とは別。全文拼音を付け、曖昧なプレースホルダーで代用しない。
- 語彙の `meaningOrigin: textbook` は原本の訳・品詞を保持したもの。
- 説明や既存HTML由来の補足は `textbookExplanation` と混ぜない。HTMLはsource/に未修正で残す。

判読不能な文は次の形で残す。文を推測した文字列を入れるとZod検証が失敗する。

```json
{"zh":null,"pinyin":null,"ja":null,"origin":"textbook","status":"needs-review","issueId":"blur-01","sourceRef":"p.XX / 写真名・位置"}
```

`lesson.issues` に同じID・位置・確認理由を記録する。該当箇所の別写真が届くまで、内容を補完せず画面に「原文要確認」を表示する。画像の解像度不足なら既知の原文と不明部分を別項目に分け、既知部分を失わない。

## 拼音・訳・解答

声調記号を使う。軽声は記号なし。了のle/liǎo、得のde/dé、只のzhī/zhǐ、固有名詞、儿化、一・不の変調を確認する。原本の表記と学習用の発音表記が違う場合は注記する。文法構造を理解できる自然な日本語訳にする。

単語分解は意味のある語・句単位とし、「文脈に応じた語句」のような空説明や漢字1文字ずつの機械分割で埋めない。全文拼音と語句の拼音を両方持つ。自由作文や会話の模範解答は一例であり、別解の可能性を表示する。

## 欠落と修正

期待掲載数はデータ配列長から自動生成しない。原本を見て独立して数える。原番号ごとの照合表・候補数・各項目の文数と解答数・設問群ごとの小問数を review.json と source/inventory.md に記録する。数が合っていても文字の誤記は検出できないため画像との目視照合も必要。

`corrections` には修正前、修正後、根拠を保存する。差異は「原本の修正」ではなく「教材の誤転記の修正」。元資料は常に未修正で保持する。
